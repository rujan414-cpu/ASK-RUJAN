Just like editing the video using computer software, an audio file can
also be edited. The file extensions of the audio file are MP3, WAV,
WMA. etc. If software or application required for audio editing are not
installed on the computer or smartphone, they can be downloaded and
installed from the windows store, app store, etc. For example, to edit
an audio file, audacity can be downloaded from ww.audacityteam.
org. Similarly, mp3 cutter software can be downloaded from any
official source by using Google search.
